# Data Visualization Assignment - Zambia Climate Profile (2021–2025)
**Course Code:** ICD5011  
**Student Name:** Mageza T. T. Mbewe  

## Project Overview
This repository contains a comprehensive data visualization portfolio analyzing synthetic climatic, demographic, and air quality profiles for Zambia's 10 provinces over a five-year timeline. The project transitions from basic single-axis configurations to multi-variable matrices and facet grid panel layouts using Matplotlib and Pandas.
